# 🌬️ Air Project(Kuzbass)

Приложение на Python с использованием Kivy и PyTorch для прогнозирования качества воздуха (концентрации PM2.5) в Кемеровской области. Проект объединяет нейронные сети для анализа экологии и современный мобильный интерфейс.

 ✨ Особенности
- Нейросетевой прогноз: Использование архитектуры LSTM (Long Short-Term Memory) для предсказания уровня загрязнения на 24 часа вперед.
- Облачная синхронизация: Авторизация и хранение данных пользователей через Firebase Realtime Database.
- Кроссплатформенный UI: Красивый графический интерфейс на Kivy.
- Безопасность: Хеширование паролей с использованием PBKDF2-SHA256 и механизм сессий.
- Новости экологии: Встроенная лента новостей о состоянии воздуха в регионе.

 🛠 Технологии
- Язык: Python 3.13
- Фреймворк UI: Kivy
- Глубокое обучение: PyTorch (LSTM Model)
- База данных: Firebase
- Библиотеки: NumPy, Requests, os, Torch, kivy
